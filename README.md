A standalone, deterministic GitHub-compatible forge built for the github-core-clone-01 checks. It runs on Node.js 22 and uses only built-in modules. The forge surfaces are REST v3, Git smart HTTP, GraphQL v4, and MCP over Streamable HTTP. No secrets are stored in this repository.

## Run it

```sh
npm start
```
